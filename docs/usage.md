# ClipboardTyper：剪贴板模拟输入器

Windows 原生托盘程序，运行仅使用 Python 标准库，无需 AutoHotkey。支持圆角状态卡片、图形配置窗口、快慢输入、暂停/继续、详细进度和错误日志。打包后的 EXE 无控制台窗口，使用者无需安装 Python。

在资源管理器中复制一个或多个普通文件后触发输入，程序会将每个文件转为带文件名边界的 Base64 文本包，而不是输入文件路径。因此文本、PNG 及其他二进制文件都可以无损传输，多文件也可明确区分。文件夹不会被当作路径输入。

将接收到的完整文本保存为 UTF-8 文件，然后执行 `scripts\split_clipboard_text.bat received.txt [输出目录]`，即可按包内的文件名重建原文件。未指定输出目录时，默认在输入文件旁创建 `<输入文件名>-files` 目录；默认不覆盖已有文件。

## 本次修复：后台保存、Citrix、按键录制与 Esc 范围

- **配置与日志后台处理**：配置文件由独立写入线程原子替换，日志通过队列交给后台线程写入、格式化异常和轮转。保存期间旧配置和旧快捷键仍有效；新增组合先预留，写入成功才切换，失败释放预留组合。保存和重载不能同时进行；保存中选择退出，会完成本次保存或处理失败后退出，消息线程继续响应。
- **Citrix Workspace**：远程桌面页面新增 Citrix 开关及可编辑的会话进程列表。默认匹配 `wfica32.exe`、`CDViewer.exe`、`Citrix.DesktopViewer.App.exe`，使用远程桌面页的快慢参数，卡片显示 `Citrix`。匹配不含 Workspace 启动器或整个浏览器。进程依据见 [Citrix 官方客户端进程说明](https://community.citrix.com/tech-zone/build/tech-papers/antivirus-best-practices/)。
- **卡片异常可追踪**：绘制、显示、窗口回调及屏幕位置更新失败会记录完整堆栈，隐藏失效卡片，并在托盘保留错误；运行中的任务会暂停。同一故障不重复刷日志。右键托盘 →「显示状态卡片」可以重试；日志可从托盘打开。
- **按键录制**：设置 →「快捷键」→ 对应动作的「录制」，等提示出现后按组合键。只填入表单，点击「保存并应用」才生效。Esc、取消按钮、切换到其他窗口或 15 秒超时会取消。录制期间不会执行本程序已绑定的快捷键动作，注入按键不会被录制。
- **防误触校验**：字母、数字必须搭配 Ctrl、Alt 或 Win，`J`、`1`、`Shift+J` 均拒绝；`F8` 等功能键仍可单独使用。手填、录制和 JSON 重载均执行校验。旧文件若配置了单字母快捷键，需要改成合法组合。
- **Esc 限定窗口**：只有原目标窗口在前台时，Esc 才中止任务。暂停后在其他软件、设置窗口或托盘菜单按 Esc，不会取消剩余文本。`Ctrl+Alt+S`（或自定义的中止快捷键）仍可全局中止。此规则也适用于关闭焦点保护的任务。

旧配置无需手工添加 Citrix 字段：缺失时自动补默认值，原 RDP 客户端列表和速度保留。`remote_desktop.enabled=false` 会关闭全部远程专用速度；只关闭 `remote_desktop.citrix_enabled` 则关闭内置 Citrix 匹配。保存设置后新字段写入文件。

Citrix 支持的是本地 Windows 会话客户端识别和专用输入速度；浏览器 HTML5 会话、后台输入和绕过客户端输入限制不在实现范围内。实际字符是否被远端接收，仍需要在你的会话中确认。

这次改动减少磁盘 I/O 阻塞监听的风险，但不保证系统永远不会移除键盘钩子。Windows 对低级钩子回调有超时限制，消息线程仍需及时处理消息。[Microsoft 低级键盘钩子文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)、[Python 队列日志文档](https://docs.python.org/3/library/logging.handlers.html#queuelistener)

## 多屏卡片与远程桌面专用速度

### 多屏定位与缩放

- 卡片默认跟随**本次输入目标窗口所在屏幕**，显示在该屏幕工作区右下角，避开任务栏；左侧/上方屏幕的负坐标也受支持。
- 在支持每屏 DPI 的 Windows 10/11 上，卡片跨屏或屏幕缩放改变时，会重新调整尺寸、字体、进度条和圆角。目标程序自身是否支持 DPI 缩放，不用于推断卡片的缩放值。
- 可按住卡片上方的标题区域拖动；菜单按钮和关闭按钮不参与拖动。拖动不主动抢走目标输入焦点。
- 拖动后保留**本次运行的位置**，后续进度更新不把它移回右下角。右键托盘 →「卡片跟随目标窗口所在屏幕」恢复自动定位。位置暂不跨重启保存。
- 显示器断开或工作区改变时，卡片会重新约束到可见工作区。目标窗口移动通过 Windows 事件通知处理，不新增空闲定时轮询。
- 设置窗口沿用系统 DPI 缩放；此次每屏动态缩放针对状态卡片。较旧系统缺少相关接口时使用系统缩放。

### 只区分远程桌面和其他程序

设置窗口新增 **「远程桌面」** 页面。开启后，在本次输入启动时检查前台窗口的客户端进程名：默认匹配 `mstsc.exe` 和 `msrdc.exe`，分别使用该页的慢速/快速参数。其他所有程序继续使用 **「通用速度」**，不建立编辑器、浏览器等应用方案。

| 场景 | 选用速度 |
| --- | --- |
| 目标进程与远程桌面客户端列表匹配，且已启用专用速度 | 远程桌面页的慢速 / 快速参数 |
| 非远程桌面客户端、识别失败，或关闭专用速度 | 通用速度页的慢速 / 快速参数 |

客户端按完整进程名匹配，不区分大小写，不匹配窗口标题或部分字符串。其他客户端可填写实际 `.exe` 进程名，多个以逗号分隔；不填写文件路径。浏览器内的远程桌面不会自动识别，避免误将浏览器所有输入都视为远程桌面。

命中专用方案时，卡片标题显示 `ClipboardTyper · RDP`，托盘状态和日志也会显示所选方案。不能获取进程名时自动回退到通用速度。若本程序运行在远端 Windows 内，检测到的是远端目标应用本身，通常应使用通用速度；专用方案用于**在本地运行程序、向本地远程桌面客户端输入**的场景。

默认远程快速参数为：`keyDelay=0`、`chunk=4`、`pause=35`、`breatherEvery=8`、`breatherPause=160`、`linePause=250`；远程慢速初始值与通用慢速相同。这些是可调整的初始值，不代表程序能检测远端是否掉字。

快捷键不变：Ctrl+J 使用所选方案的慢速，Ctrl+K 使用快速。方案及参数在任务开始时固定，暂停后更改配置不会改变当前任务。

任务暂停时按 Ctrl+J 或 Ctrl+K，会先中止旧任务，等旧输入线程退出，再从当前剪贴板开始一个慢速或快速新任务，进度从零计算。新任务使用当前输入窗口和最新配置；如需接着旧任务输入，请按 F8。等待松开快捷键、正在中止任务、设置窗口未关闭等情况会在状态卡片和托盘显示提示；若在任务交接期间切换窗口，本次新任务取消，点击目标位置后重新按快捷键即可。

旧配置文件可继续使用：未填写 `remote_desktop` 时补充默认值，已有通用参数保留。用 GUI 保存后新字段写入原文件。重打包仍不覆盖已有的 `dist/settings.json`。

### 焦点移开后能否继续输入原窗口？

**当前版本不能可靠地向失焦的远程桌面窗口继续模拟输入。** 本程序使用 `SendInput`，键盘输入发往有焦点的前台线程/窗口；这个接口不接受一个指定后台目标窗口。切换到别的窗口后，默认暂停。切回原输入位置按 F8，或从托盘选择「继续输入」，可以接着未完成的位置输入。[Windows 键盘输入说明](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-keyboard-input)、[SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)

取消「保护原输入窗口」不会启用后台输入，会让后续按键有可能进入新焦点窗口。设置页已明确标注。若需要切走后远端仍持续执行，适合把实际工作改成在远端运行的脚本、命令或应用 API；不能把本地继续向后台 RDP 发键视为通用可靠方案。

## 状态卡片和设置窗口

- **状态卡片**：约 380 × 190 个逻辑像素的白底圆角卡片，默认位于目标屏幕右下角，可拖动。用蓝色 / 琥珀色 / 绿色 / 红色区分输入中、暂停、完成和错误，显示进度条、百分比及字符计数；不抢输入焦点。
- **隐藏卡片**：右键卡片或托盘 →「隐藏状态卡片」，也可点击卡片右上角 `×`。`×` 只隐藏界面，不退出程序。
- **重新显示**：右键托盘 →「显示状态卡片」。隐藏会持续到本次运行结束，普通进度更新、新任务和错误不会自行把卡片重新弹出。错误仍保留在托盘和日志。
- **输入不丢失**：打开右键菜单时先暂停；若此前正在输入，选择隐藏后会尝试恢复原窗口并继续。若此前已暂停，则继续保持暂停。窗口恢复失败时，回到原输入位置按暂停/继续快捷键。
- **图形配置**：双击托盘，或右键 →「设置…」。窗口提供「通用速度」「远程桌面」「快捷键」「显示与保护」四个页面，包含所有可配置参数。无需手写 JSON。
- **保存并应用**：点击按钮或按 Ctrl+S，校验后保存至原 `settings.json` 并应用。快捷键被占用、输入无效或文件无法写入时显示持续的错误说明；原文件、旧快捷键和运行配置保持有效。
- **恢复默认值**：只填充表单，点击「保存并应用」后才生效。关闭设置窗口会丢弃未保存的编辑，程序继续在托盘运行。

打开设置会暂停当前任务；设置窗口关闭前，不允许新建输入任务或恢复输入，避免把内容打进配置表单。关闭后回到原输入位置，再按暂停/继续快捷键。已暂停任务保留原速度；新速度在下一次新任务生效。

设置窗口未关闭时按慢速、快速或暂停/继续快捷键，窗口底部和状态卡片都会提示先关闭设置。普通提示显示期间，状态卡片优先显示完整提示，之后恢复进度显示。更新后请运行新生成的 `dist/ClipboardTyper.exe`；其他目录中的旧 EXE 不会自动更新。

「显示与保护」页面的「显示状态卡片」控制保存后的默认显示偏好。若希望今后启动也不显示，可取消并保存。托盘的隐藏/显示是当前会话的临时控制，不改写配置文件；显示选项开启后，已经手动隐藏的卡片仍需从托盘重新显示。

配置窗口使用 Python 自带的 tkinter/ttk，不新增 pip 运行依赖；打包时需要 Python 安装包含 Tcl/Tk（官方 Windows 安装器的 Tcl/Tk and IDLE 选项）。

## 保留的输入优化

| 问题 | 修复后的行为 |
| --- | --- |
| 快速模式仍逐字调用发送 | `keyDelay` 为 `0` 或 `-1` 时，每个块只调用一次 `SendInput`；默认每块 12 个字符。 |
| 改速度或快捷键必须重新打包 | 使用 EXE 旁的 `settings.json`，从托盘重新加载。快捷键注册失败会保留旧绑定和旧配置。 |
| 空闲每约 5ms 轮询 | 主线程通过 `MsgWaitForMultipleObjectsEx` 阻塞等待消息、任务通知和退出事件。 |
| 手动按住修饰键仍继续输入 | 物理 Ctrl、Alt、Shift、Win 会自动暂停；程序注入的按键不触发此保护。 |
| 进度不具体、错误转瞬即逝 | 常驻状态窗显示已发送数、百分比、行号和剩余数；错误持续显示，托盘可查看详情和日志。 |

## 在 Windows 上生成 EXE

1. 安装 Windows Python 3.9 或以上版本，确保 `py` 或 `python` 命令可用。
2. 完整解压项目，保留 `src/`、`scripts/`、`pyproject.toml`、`settings.json` 和 `build_exe.bat` 的目录结构。
3. 先右键退出正在运行的旧程序，再双击 `build_exe.bat`。
4. 成功后运行 `dist\ClipboardTyper.exe`。同目录会有 `settings.json`，可一起复制到其他电脑。

首次打包需要联网安装 PyInstaller。`build_exe.bat` 自动创建或复用项目的 `.venv-build` 并安装打包依赖，无需全局安装 PyInstaller，也无需单独运行安装脚本。

重复打包会复用构建缓存；项目元数据、Python 和已安装包版本未变化时跳过依赖安装。需要重新分析时使用 `build_exe.bat --clean`，需要重新安装依赖时使用 `build_exe.bat --refresh-deps`。可组合参数，自动化运行时添加 `--no-pause`。

如果更重视启动速度，执行 `build_exe.bat --onedir`，然后运行 `dist\ClipboardTyper\ClipboardTyper.exe`。目录版减少单文件版每次启动的解压开销；**必须复制整个 `dist\ClipboardTyper` 文件夹**，包含 `_internal`，不能只复制 EXE。目录版配置位于 `dist\ClipboardTyper\settings.json`，重打包同样保留；首次从项目根目录复制，不自动沿用单文件版配置。单文件版仍为默认，也可显式使用 `--onefile`。

重打包时会保留已有的 `dist\settings.json`，不会覆盖你的自定义参数。首次生成时从项目目录复制配置。**运行 EXE 时，请编辑 `dist` 内、EXE 旁的配置**，或直接使用托盘的「编辑配置」，避免改错文件。

本次升级涉及代码，需要重新打包一次；以后只调整配置，无需再打包。也可执行 `python -m clipboard_typer`（先执行 `python -m pip install -e .`） 直接运行源代码。

## 默认快捷键和托盘操作

先复制文本，点击目标输入位置，再按快捷键并松开。

| 操作 | 功能 |
| --- | --- |
| Ctrl+J | 慢速输入 |
| Ctrl+K | 快速输入 |
| F8 | 暂停 / 继续 |
| Esc | 仅在原目标窗口中止任务 |
| Ctrl+Alt+S | 全局中止当前任务 |
| Ctrl+Alt+Q | 退出程序 |
| 右键托盘 → 继续输入 | 尝试激活原窗口并从暂停位置继续 |
| 双击托盘或右键 → 设置… | 图形配置窗口，保存并应用 |
| 右键卡片或托盘 → 隐藏状态卡片 | 隐藏弹窗，保留任务 |
| 右键托盘 → 显示状态卡片 | 恢复弹窗 |
| 右键托盘 → 编辑 JSON 配置（高级）/ 重新加载配置 | 手动编辑 JSON 后应用 |
| 右键托盘 → 查看最近错误 / 打开日志 | 查看完整错误和历史记录 |
| 右键托盘 → 确认错误 | 收起常驻错误提示，保留错误记录 |
| 右键托盘 → 退出程序 | 中止任务、移除图标并退出 |

托盘位于任务栏时钟旁；看不到图标时点击 `^` 展开隐藏图标。Esc 是固定的目标窗口中止键，其余表中快捷键可配置。托盘菜单打开时 Esc 只关闭菜单；录制时 Esc 取消录制。

## 修改配置，无需重新打包

推荐使用右键托盘 → **设置…** → 修改表单 → **保存并应用**。

如需手动编辑 JSON：右键托盘 → **编辑 JSON 配置（高级）** → 在记事本中修改并保存 → 右键托盘 → **重新加载配置**。

- 快捷键立即生效。配置错误、重复快捷键或快捷键被其他程序占用时，本次配置不应用，旧配置继续有效。
- 速度和输入选项从下一次新任务生效。已暂停任务保持原参数和位置，使用更新后的暂停/继续快捷键恢复。
- 状态窗是否显示及进度显示设置在重载后立即应用。
- 编辑、重载配置会暂停正在输入的任务，完成后回到原输入位置，按暂停/继续快捷键恢复。
- 配置使用标准 JSON：双引号，布尔值为 `true` / `false`，不允许注释或尾随逗号。未知字段或超出范围的数值会报错。省略字段使用默认值。

例如，下面是可直接使用的精简配置：将快速模式每块改为 24 个字符，块间停顿 20ms，暂停/继续改为 F9，其余使用默认值。

```json
{
  "version": 1,
  "profiles": {
    "fast": {
      "keyDelay": 0,
      "chunk": 24,
      "pause": 20
    }
  },
  "hotkeys": {
    "pause_resume": "F9"
  }
}
```

EXE 从自身目录读取配置，源码/可编辑安装从项目根目录读取；普通包安装使用用户数据目录，不依赖启动时的工作目录。可通过 `clipboard-typer run --config PATH` 或 `CLIPBOARD_TYPER_CONFIG` 指定文件。配置不存在时会生成默认文件；该目录无法写入时，改用 `%LOCALAPPDATA%\ClipboardTyper\settings.json`。托盘「编辑 JSON 配置（高级）」始终打开实际使用的文件。启动时配置损坏会显示常驻错误并暂用默认值，不覆盖损坏文件，修正后可重新加载。

### 速度参数

`profiles.slow` / `profiles.fast` 分别控制两种模式，时间单位为毫秒。

| 参数 | 默认慢速 / 快速 | 含义 |
| --- | --- | --- |
| `keyDelay` | 10 / 0 | 逐字符发送后的停顿，实际至少 10ms；旧值 0 / -1 也按 10ms 执行。范围 -1～60000。 |
| `chunk` | 1 / 12 | 每块源文本字符数，范围 1～256；换行单独处理。 |
| `pause` | 50 / 15 | 每块之后的停顿，范围 0～60000。 |
| `breatherEvery` | 10 / 8 | 每多少块长停顿一次；0 关闭。每行重新计数。 |
| `breatherPause` | 400 / 80 | 长停顿时长，范围 0～60000。 |
| `linePause` | 400 / 120 | 换行处理后的停顿，范围 0～60000。 |

所有模式均逐字符调用 `SendInput`，每字至少留出 10ms，让目标软件处理 Unicode 输入，降低中文、英文或标点在批量发送时重复、丢失的风险。emoji 等补充字符的 UTF-16 代理对保持在同一次发送中。`chunk` 仍控制追加块间停顿和长停顿的频率，不再把整块文本一次注入。旧配置无需修改；快速模式会比旧版慢。若目标软件或远程会话仍出现重复、掉字，可提高 `keyDelay`（例如 30～50ms）或改用慢速；该间隔不能保证所有目标软件都已接收。

### 快捷键参数

`hotkeys` 包含 `slow`、`fast`、`pause_resume`、`stop`、`quit`。例如 `Ctrl+Alt+P`、`F9`、`Ctrl+Shift+K`。字母和数字必须搭配 Ctrl、Alt 或 Win，不能单独使用或仅搭配 Shift。修饰键支持 Ctrl、Alt、Shift、Win；主键支持字母、数字、F1～F24（F12 除外）、Pause、ScrollLock、Insert、Home、End、PageUp、PageDown。避免选择目标软件常用或系统保留的组合。F12 由 Windows 保留用于调试器，因此配置校验拒绝它。[RegisterHotKey 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)

## 暂停、恢复与修饰键保护

- 输入时按 F8 或物理 Ctrl / Alt / Shift / Win 会暂停。**松开修饰键不会自动继续**；回到原输入位置，按 F8 并松开后恢复。若修改了快捷键，使用配置后的键。
- 启动快捷键自身的 Ctrl 会先等待释放，不会把新任务直接变成手动暂停。
- 程序自身注入的 Shift（例如清理缩进）不会触发物理按键保护。
- 默认切换窗口自动暂停；切回原窗口按 F8。托盘「继续输入」会尝试激活原窗口，激活失败则保持暂停并提示。
- 打开托盘菜单会自动暂停，关闭菜单后保持暂停；选择「隐藏状态卡片」会尝试恢复此前正在进行的输入。暂停期间 Ctrl+J / Ctrl+K 不会另起任务。
- 暂停保留剪贴板快照和发送位置；改变剪贴板不会改变已经读取的当前任务。
- 暂停时可以中止或退出。原窗口关闭也会中止。退出、重复启动或中止后不会保存剩余任务。

每个字符发送前及等待期间均检查暂停和中止，已经进入 Windows 输入队列的按键无法撤回。窗口保护只识别顶层窗口，不区分其中的不同输入框；暂停期间请保持原光标位置和已输入内容不变。

## 进度、错误与日志

状态窗和托盘提供类似 `已发送 1,200/4,800 (25.0%)  第 5/20 行  剩余 3,600` 的进度。计数使用规范化换行后的源文本字符数：CRLF 视为一个换行，普通 emoji 可占一个源字符，组合 emoji 可能占多个；自动缩进清理按键不计数。

**进度表示已提交给 Windows 的源字符数量，不能确认目标软件实际接收了多少字。** `SendInput` 失败会停止任务并记录错误，不会把失败的字符计为成功；若该字符的部分事件已送入，目标中可能已有其内容。[SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)

错误提示不会被普通提示或进度更新覆盖。右键托盘可查看最近错误、打开日志或确认错误；明确启动一个新任务也会收起原错误提示。确认后仍可查看最近错误和日志。关闭 `show_popup` 时，错误仍保留在托盘和日志中。

日志位置：`%LOCALAPPDATA%\ClipboardTyper\clipboard_typer.log`。包含时间、运行状态和完整异常堆栈，不记录剪贴板正文。每份约 1 MiB，保留最多 3 份历史日志。

空闲主线程采用 Windows 消息/事件等待，不再每 5ms 醒来。临时提示到期和托盘恢复重试仍有定时唤醒；有任务且暂停时，工作线程每约 250ms 检查原窗口是否关闭。首次打开设置后，独立 Tk 线程每 50ms 检查通知队列，保存结果由 Tk 自己的定时回调处理，避免从 Windows 原生回调重入 Tk 导致整个进程崩溃。[MsgWaitForMultipleObjectsEx 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-msgwaitformultipleobjectsex)

## 常见问题

- **快捷键被占用**：关闭占用该组合的旧脚本或其他程序，也可通过托盘编辑配置并重载。运行中重载失败保留旧绑定。
- **不能向管理员程序输入**：本程序也需要相应权限；Windows 对模拟输入有进程权限限制。[SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)
- **重打包失败**：先右键托盘退出运行中的旧 EXE，再重试。
- **提示缺少 tkinter / Tcl/Tk**：使用 Windows Python 安装器的 Modify 功能，勾选 Tcl/Tk and IDLE，然后重新打包。
- **下载 PyInstaller 失败**：检查网络、代理和 Python 包源。目标电脑运行已生成 EXE 时无需联网安装这些依赖。
- **设置似乎没变化**：确认编辑了正在运行的 EXE 旁配置，保存后选择「重新加载配置」。速度在下一次新任务生效，暂停任务继续使用旧速度。
- **重复启动**：新实例会通知旧实例退出再接管快捷键。Explorer 重启后会尝试恢复托盘图标。
